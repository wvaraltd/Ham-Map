# ARA Ham Map

Complete saved Ham Map backend v0.3.1 source and Debian/Apache deployment tools are in app/ and deploy/; see README.txt and install-debian.sh. The saved Site frontend is in site-frontend/dist/, imported from commit 493fbab0e28f82bf6266fb38c105835bc18cd9da. Saved historical packages are extracted under history/ for inspection. Runtime databases, hosting credential metadata, and live secrets are excluded.

This source archive does not change the running Ham Map website. ARA's other projects are in https://github.com/wvaraltd/ARA-Projects.
